# resources/ — 外部资料(人工维护)

放做研究时要参考的外部材料:论文 PDF、外部文档/说明书、别处摘来的笔记 md、图表等。
与 `docs/` 的区别:`docs/` 是**本项目产出的记忆**(计划、发现、知识);这里是**外部输入的原材料**。

## 纪律

- **人工维护,agent 只读不写**:agent 可以读取并引用这里的内容(例:让它读某篇论文的方法一节),但不主动写入、重命名、整理或删除;需要往这里放东西时,由 agent 提议、我来放。
- **进 git 的**:`.md` / `.txt` / `.bib` 等小文本 —— 随仓库迁移,换机器 `git clone` 就有,agent 也能直接读。
- **不进 git 的**:`.pdf` / office 文档 / 压缩包 / 音视频等大件(见 `.gitignore` 的 `resources/**` 段)—— 换机器需按来源重新下载。
- **大件要登记来源**:凡是不进 git、但后续还要用的材料,在下面的清单里记一行(标题 + 出处链接/DOI),否则换机器就找不回来了。若某个大件是**复现实验所必需**的(不只是参考读物),按 `env/external_deps.md` 的模板登记并钉死版本。
