> 1. pydantic是啥 2. slot_seconds和horizon_seconds是啥

**1. pydantic 是什么**

pydantic 是一个 Python 库：你用类声明"数据应该长什么样"，它在创建对象时自动检查数据并转换类型，不合格就直接报错。

```python
class NetAgentConfig(BaseModel):
    slot_seconds: PositiveInt

NetAgentConfig(slot_seconds=900)    # 通过
NetAgentConfig(slot_seconds="900")  # 通过，字符串自动转成 int
NetAgentConfig(slot_seconds=0)      # 报错：必须为正
NetAgentConfig(slot_secs=900)       # 报错：缺 slot_seconds；因为设了 extra="forbid"，多余字段也报错

```

我们用它做两件事：

- 第 0 步：检查参数文件。
- 第 1 步：检查 agent 之间的消息，例如时间窗是否前后颠倒、bytes 是否为负。坏数据在入口就被拦下，不会流进账本。

**2. slot_seconds 和 horizon_seconds 是什么**

两者都是 ledger 的参数。ledger 是一张"每条链路 × 时间段"的容量表，对应 slide 23：

```
链路 ANL–ESnet   09:00  09:15  09:30  09:45  ...  （一直排到 horizon 为止）
available(Gbps)    60     60    100     40  ...

```

- `slot_seconds`**：每一格代表多长时间。** 900 就是 15 分钟一格，表里同一格内的可用容量视为不变。格子越小，预留越精确，但计算量越大；格子越大，零头浪费越多。
- `horizon_seconds`**：这张表往未来看多远。** 86400 就是 24 小时。超过这个范围的请求无法报价，因为表里还没有那么远的时间段。随着时间推进，表在前面补上新格子，在后面丢掉过期的格子。

两者一除就是格子数：86400 / 900 = 96 格。

## 值得看的两处

**1. 参数不设默认值**（[config.py:14-19](../../src/lib/network_agent/config.py#L14-L19)）

CLAUDE.md §6 要求影响结果的参数只能来自 config 文件。所以 `NetAgentConfig` 的字段都没有默认值，再加上 `extra="forbid"`，漏写、拼错、填了非正数都会在加载时直接报错，不会悄悄用上某个默认数字。测试里的三种坏输入就是在验证这一点。

现在只有三个参数：


| 参数                    | 含义                        | 首次用到  |
| --------------------- | ------------------------- | ----- |
| `slot_seconds`        | 账本时间槽长度                   | 第 2 步 |
| `horizon_seconds`     | 账本向前看多远                   | 第 2 步 |
| `reserve_ttl_seconds` | reserve 未 commit 时自动释放的期限 | 第 5 步 |


后面哪一步需要新参数，再往这里加。
