## 三、HPE 硬件讨论



### 1. Phase 1 提供什么

一位与会者问 HPE 何时提供硬件、是否在 Phase 1。HPE 侧答复：在 Phase 1，设想提供一台带 **Trio ASIC** 的 **Juniper** 交换机（转写为 “Toyoasic”），细节再与 Harvey 讨论。

> 我没懂我的理解是phase1基本是基于VIT这个仿真器做的，为什么还要“在 Phase 1，设想提供一台带 Trio ASIC 的 Juniper 交换机”?

你的理解是对的，PM 也确认了：Phase 1 的核心是在 VIT 上证明技术可行。会上没人专门解释为什么还要交换机，按上下文主要有三个原因：

1. **HPE 在 proposal 里承诺了要提供硬件。**PM 要求每个 partner 都"做 proposal 里写的事"，HPE 的分工之一就是 providing infrastructure。所以这台交换机主要是在兑现 HPE 自己的承诺。
2. **Proposal 里有一个 task 要在加速硬件上跑 workflow。**按主持人的复述，那个 task 既要在网络 digital twin 上展示高能物理的运行，也要在加速硬件上跑 workflows。后一半需要真实设备，而 Harvey 那边的高能物理大流量传输本来就跑在真实硬件上。
3. **为 Phase 2 做准备。**HPE 自己说了，P4、multipath 这些"有意思的功能"主要放到 Phase 2。提前拿到设备，Phase 2 才有现成的基础。

不过这块硬件主要是 Harvey、HPE 和 John 之间的事。我们组在 Phase 1 的主线还是 VIT 上的 demo，硬件只是并行的一条线。Mariam 也要求每项硬件动作都要说清楚它帮的是哪个 month-six milestone，说明她同样不希望硬件分散 Phase 1 的重心。

### 2. 服务器需求与 bill of materials

HPE 侧询问，在交换机之外，需要什么样的通用服务器来推送数据或运行科学 workflows。答复（推测为 Harvey）：需要能够支撑**大规模数据流**的系统。他手上有示例 bill of materials（BOM）：

- 一个 **Gen5** 示例（与 Internet2 相关，含几台服务器）；
- **Gen6** 的配置更有挑战性。

HPE 侧表示：网络硬件较容易，大部分已有规格，只需确定即可；服务器更复杂。请对方把 BOM 发过来，HPE 侧看能拼出什么样的 HPE 版本，不必照单全收，而是讨论一个合理配置。

> - **Juniper**：Juniper Networks，老牌路由器、交换机厂商，2025 年被 HPE 收购。所以 HPE 提供的网络设备会是 Juniper 的。
> - **Trio ASIC**：Juniper 自研的转发芯片系列，用在 MX 系列路由器等设备里。ASIC 是为特定用途定制的芯片，Trio 专门负责高速转发数据包。它的特点是可编程，所以会上 HPE 的人说可以在上面"定义自己的 SDN 协议，不只是 P4"。
> - **Bill of materials（BOM，物料清单）**：组装一台设备需要的全部部件清单，比如 CPU、内存、网卡（含 BlueField）、硬盘的型号和数量。会上的意思是：Harvey 把他们现有的服务器配置清单发给 HPE，HPE 照着看能用自家产品拼出什么样的等价配置。
> - **BlueField** 是 NVIDIA 的 DPU（data processing unit），可以理解为一块"自带电脑的智能网卡"。网卡上有自己的 Arm CPU 和加速器，能把网络、存储、安全相关的处理从主机 CPU 上搬走。这条产品线来自 NVIDIA 收购的 Mellanox。
> - **BlueField-3 / 4** 是代际。BlueField-3 是目前常见的一代，最高 400Gb/s；BlueField-4 是新一代，带宽更高。
> - **DOCA** 是 NVIDIA 给 BlueField 配的软件开发包，相当于在网卡上写程序的工具。

### 3. P4 能力放在哪里

有人问是否需要服务器端具备 P4 能力，以及是在 edge 还是 network core 做 P4（并提到 Harvey 已有 **Tofino** 1 P4 交换机）。HPE 侧答复：

- Phase 2 中这会很重要，用于 multipathing 等更有意思的功能；
- 服务器端的 P4 主要取决于选用哪些 NIC；HPE 自己也有交换机可用；
- 前面提到的 Trio ASIC 交换机某种程度上可以自定义 SDN 协议，不限于 P4；
- **应把大量 P4 相关工作推到 Phase 2**。本项目更侧重网络侧，而非整体基础设施；Phase 1 优先展示加速的 workflows 及其数据如何经网络推送，并在 month six 前完成相关 milestones。



### 4. BlueField

一位与会者建议请 HPE 在服务器中配置 **BlueField-3 或 BlueField-4**（视架构而定），因为它们能做 host-based networking，在 **DOCA** 中带来 P4、RDMA、BGP peering 等能力。HPE 侧回应：NVIDIA 已把其中许多产品列为 end-of-life，需要看现有可用货源；据其了解，获取新的 BlueField（至少 BlueField-3）非常困难，但会去查 HPE 自己的 BlueField 选项。对方建议尽早向 HPE 询问。
